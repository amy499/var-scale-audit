# P2 Phase F: DiT corruption on real crystal images (jobs `26090194`, `26090195`)

Transfer check (`lanes/p2/transfer.py`, `jobs/phasef.pbs`): 64 real microscopy images, each image's VAE
latent noised to timestep 197 and denoised by DiT-XL/2 (cfg 1), once clean and once with `noise_x`
(`sigma` scale) at timestep 96 or 36, severities 0.5 / 1 / 2. Run twice, conditioned on two unrelated
classes (`26090194`: class 0, tench; `26090195`: class 973, coral reef; see each job's `manifest.csv`).

Data: OpenCrystalData, "In-line Image Characterization using EasyViewer" (CC-BY-SA-4.0;
https://www.kaggle.com/datasets/opencrystaldata/easyviewer-based-image-characterization; Barhate et al.,
Digital Chemical Engineering, 2024). 64 files evenly spaced over the sorted file list.

PSNR to the real image (dB), hf_ratio (texture vs the real image) in brackets:

| Run | Class 0 | Class 973 |
|---|---|---|
| VAE reconstruction only | 29.68 (0.90) | 29.68 (0.90) |
| start t197, no noise | 21.68 (1.00) | 21.67 (0.94) |
| + noise at t96, severity 0.5 | 21.31 (1.00) | 21.31 (0.93) |
| + noise at t96, severity 1 | 20.04 (0.87) | 20.02 (0.83) |
| + noise at t96, severity 2 | 15.94 (1.12) | 15.89 (1.11) |
| + noise at t36, severity 0.5 | 21.61 (1.01) | 21.60 (0.94) |
| + noise at t36, severity 1 | 21.39 (1.01) | 21.38 (0.95) |
| + noise at t36, severity 2 | 20.53 (0.90) | 20.50 (0.85) |

PSNR lost to the corruption (vs the no-noise run from t197; both classes within 0.05 dB):

| Noise at | Severity 0.5 | 1 | 2 |
|---|---|---|---|
| t96 | -0.4 | -1.6 | -5.8 |
| t36 | -0.1 | -0.3 | -1.2 |

- **Earlier noise sticks, late noise is absorbed:** at every severity t96 costs 4-6x what t36 does, the
  same ordering as Figure 2's DiT (σ) line on ImageNet. The finding transfers to out-of-domain images.
- **Not driven by the class prior:** the two classes agree to 0.05 dB; only texture differs (about 6%).
- **Two failure modes at t96:** severity 1 smooths the crystals (hf_ratio drops to 0.83-0.87); severity 2
  leaves speckle (hf_ratio 1.11-1.12).
- Starts are capped at t197: from t297 the class prior replaces the crystals (`../phasef_pilot/`). Even at
  t197 some images grow fish-like blobs (`grid.jpg`, DiT row 2).

## VAR pilot (job `26090204`, 16 images, class 0, cfg 0)

The real image's VQ tokens at scales 0..k (teacher forcing, `real_h`), the rest generated by VAR-d20;
`noise_h` (`rel`, severity 2) at scale 6 or 8. Check: real scales 0-9 give 26.16 dB vs 26.19 dB for the VQ
reconstruction, so the hook reproduces the image.

| Real scales | No noise | + noise at scale 6 | + noise at scale 8 |
|---|---|---|---|
| 0-2 | 16.65 (1.39) | 15.37 (2.00) | 15.67 (1.68) |
| 0-5 | 19.96 (0.92) | 17.67 (1.52) | 18.14 (1.29) |
| 0-9 (check) | 26.16 (0.83) | | |

- **Earlier is worse here too:** scale 6 costs 2.3 dB, scale 8 1.8 dB (from scales 0-5).
- **VAR adds texture, DiT smooths or speckles:** hf_ratio rises to 1.3-2.0; the corrupted images keep the
  layout with invented crystal-like grain (`grid.jpg`, VAR rows), matching re-routing in Figure 2.
- Compare drops, not absolute PSNR: the VQ codec reconstructs at 26.2 dB, the DiT VAE at 29.7 dB.

## VAR, 64 images (jobs `26090672`: class 0, `26090673`: class 973)

Real scales 0-5, `noise_h` (`rel`) at scale 6 or 8. VQ reconstruction 26.48 dB (0.87) for both.

| Run | Class 0 | Class 973 |
|---|---|---|
| real scales 0-5, no noise | 19.96 (0.95) | 20.00 (0.86) |
| + noise at scale 6, severity 0.5 / 1 / 2 | 19.82 / 19.32 / 17.68 | 19.88 / 19.40 / 17.73 |
| + noise at scale 8, severity 0.5 / 1 / 2 | 19.87 / 19.54 / 18.24 | 19.90 / 19.61 / 18.36 |

PSNR lost to the corruption (both classes within 0.1 dB):

| Noise at | Severity 0.5 | 1 | 2 |
|---|---|---|---|
| scale 6 | -0.1 | -0.6 | -2.3 |
| scale 8 | -0.1 | -0.4 | -1.7 |

- **Earlier is worse, but only by 1.3-1.5x** (DiT: 4-6x between t96 and t36). VAR's late scales do not
  absorb noise the way DiT's last steps do, as in Figure 2 (panels C-D).
- **Texture rises with severity** (hf_ratio up to 1.46 at scale 6, severity 2): VAR keeps the noise as
  invented grain rather than removing it.
- Severities are `rel` (VAR) vs `sigma` (DiT): compare the early-vs-late ratio across models, not dB values.

`grid.jpg`: 4 images per model; DiT from `26090194` (64 images), VAR from the pilot.
